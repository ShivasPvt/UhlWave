Encryption

✓ Encrypted in transit. When the app is served over HTTPS (as on Render), messages are encrypted between your device and the server.

! Encrypted in storage. Messages, photos, voice notes and files are stored encrypted (AES-256-GCM), so a leaked or stolen database can't be read.

✓ Secret chats are end-to-end encrypted. In a 🔒 secret chat, messages are encrypted in your browser and only you and the other person can read them, not even the server. Compare the security code to be sure.

! Normal chats aren't end-to-end. The server holds the key for normal chats, so it could read them while it's running. That's what lets @ai, search and backups work. Use a secret chat for anything private.

! @ai uses an outside service. When someone asks @ai, the chat's recent messages, photos, voice notes, files and shared locations are sent to the AI service (Groq) so it can answer. Weather and place lookups go to Open-Meteo.

✓ Calls go device to device. Voice and video travel directly between the two browsers, encrypted (WebRTC). The server only helps them find each other and isn't in the call.

! Pictures and GIFs use outside services. /imagine sends your description to an image service (Pollinations or Hugging Face). GIF search goes to GIPHY.

✓ Location only when you share it. UhlWave never tracks you. Your location is sent only when you tap the pin button, and everyone in that chat can see it.
